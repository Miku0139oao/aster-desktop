# 日誌與連線查閱

日誌與連線的搜尋、篩選、捲動位置與開啟的明細，在本次程式執行期間切頁後保留。寬視窗可在右側查看明細並切換項目，小視窗使用可捲動的對話框。各頁不再顯示全域匯入加號；首頁與訂閱頁保留匯入入口，新增節點、應用程式與規則在各自頁面操作。

## 日誌

可同時選取多個層級，依核心／桌面來源篩選。時間、層級與訊息分開顯示，支援 logrus 文字、JSON 及方括號層級，`warn` 統一為 warning；顯示前移除 ANSI 色碼。點選一筆可查看完整原文與複製。捲動或開啟明細自動暫停列表，避免新紀錄移動閱讀位置；背景緩衝繼續更新，按播放或「回到即時日誌」重新載入最新資料。

複製／匯出目前篩選結果時，由舊到新輸出並遮蔽常見憑證。這只遮蔽已知格式，不代表任意日誌一定沒有私人內容。核心原本設定的日誌層級仍決定哪些紀錄會產生；例如核心只輸出 warning 時，選擇 info 不會補回未產生的紀錄。核心緩衝上限約 2,000 筆，查閱中的暫停快照不受緩衝輪替影響。

## 連線

協定、程式、出口與入口可同時篩選。額外篩選在寬視窗直接顯示，小視窗按「更多篩選」展開。程式選項以完整路徑保持身分，同名程式不混為一組；選項內可搜尋路徑。彙整列可點入該程式／出口的精確篩選。Aster 自身流量預設仍可見，標示為自身連線，可勾選隱藏。

選取明細可查看核心回報的程序與路徑、來源、目的 IP、入口、出口鏈、命中規則與流量，並建立分流規則、複製或中止。寬視窗的明細跟隨同一連線更新；連線結束後保留最後資料並標記。暫停列表不暫停流量統計。中止只處理確認時捕捉的連線 ID，最多同時送出八個要求，部分失敗保留錯誤及未中止項目，不鎖住全域操作。

來源程序是核心在本機查詢 socket 擁有者的結果。桌面執行設定強制 `find-process-mode: always`，匯入原文不變。缺少資料會顯示未知，不猜測；被其他本機代理轉接的流量可能只能辨識到該代理。程序辨識／權限及 TUN 的實機行為與 UI 測試分開記錄。

## 搜尋語法

多個詞以 AND 組合，`-` 排除詞，雙引號保持片語；比對不區分大小寫，文字按字面搜尋。

| 範例 | 結果 |
| --- | --- |
| `dial timeout -udp` | 同時包含 dial、timeout，排除 udp |
| `"connection reset"` | 搜尋完整片語 |
| `level:warning source:core` | 核心 warning 日誌 |
| `app:browser host:example.com -rule:GeoIP` | 依程式、主機及規則組合搜尋連線 |
| `route:Tokyo inbound:TUN` | 指定出口鏈與入口 |
| `ip:192.0.2.1 type:tcp` | 指定來源／目的 IP 及協定 |

連線可用 `app`、`host`、`ip`、`route`、`rule`、`type`、`inbound`；日誌可用 `level`、`source`、`message`。不認得的欄位前綴視為原始文字，因此 IPv4:port、IPv6 及 Windows 路徑仍可直接搜尋。
