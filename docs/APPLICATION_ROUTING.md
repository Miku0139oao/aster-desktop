# 從 GUI 管理應用程式出口

進階設定 → 應用程式分流 → 新增應用程式。選擇程式後，下一步決定出口；不需要手動輸入程序名稱。

- **應用程式**：已安裝及可辨識的一般程式，執行中的排在前面。圖示無法取得時顯示名稱首字。
- **正在執行**：目前程序，包括獨立的網路輔助程序。
- **所有程序**：完整可讀取的清單，包含背景程序和未執行的已安裝程式。
- 搜尋支援應用程式名稱與路徑。只有一個結果時可按 Enter 選取；多個結果仍需明確選擇。
- 按程式旁的資訊按鈕查看實際比對的完整執行檔路徑。同名程式的身分與規則各自獨立。
- 出口可搜尋及自由選代理群組、具體節點、直連、封鎖。群組跟隨共用選擇；具體 provider 節點保留原本各應用獨立選擇行為。

未執行的程式來源：Windows 開始功能表捷徑、Mac 使用者／系統 Applications、Linux XDG 桌面入口。安裝清單快取 30 秒，執行狀態在重新整理時更新。可攜程式、商店啟動器、Flatpak／Snap 或只負責啟動別的程序的捷徑可能沒有可可靠比對的執行檔；先開啟程式後，從「正在執行」選取，或使用「選擇其他應用程式」。探索清單不會啟動程式，也不讀取執行中程序的命令列參數。

使用「代理所有應用程式」與規則模式接管流量；變更適用於新連線。每條規則比對所選執行檔，另外使用不同執行檔的輔助程序可從清單加入。完整路徑規則可區分同名程式；若更新改變執行檔位置，重新選取程式並移除舊規則。已有 YAML 的程序規則保留原本比對方式，訂閱更新會保留 GUI 規則。

Windows 圖示讀取在隱藏、限時的背景程序完成；Mac 使用 NSWorkspace 取得縮小圖示；Linux 使用可讀取的 PNG 桌面圖示。圖示資料限制大小，清單採可見項目繪製，背景輪詢不需要重新掃描安裝清單。Mac 安裝清單與圖示經原生 Mac CI 驗證；實際 TUN／權限仍需實機驗收。
