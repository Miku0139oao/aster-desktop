Aster Desktop 專案知識庫 (Wiki)

一款基於 Material 3 設計語言打造的現代化跨平台桌面代理客戶端。前端以 Flutter 呈現流暢直觀的使用者體驗，底層由 Go 語言編寫的 aster-bridge 與 aster-core 提供高效能系統代理、TUN 虛擬網卡接管與應用程式級分流能力。

✨ 六大核心功能模組

Aster Desktop 將複雜的網路代理配置封裝為直觀的 Material 3 桌面操作介面

📡

訂閱與節點管理

支援遠端訂閱連結匯入與定期更新，內建 yaml 解析與 re_editor 程式碼編輯器，提供靈活的節點選擇與連線策略切換。

⚡

一鍵快速連線

主畫面配備直觀的大尺寸連線切換開關，即時透過 WebSocket 與 Go Bridge 同步當前連線狀態、上下行速率與累積流量統計。

🛡️

雙重代理接管模式

支援輕量級「系統代理 (System Proxy)」與底層「TUN 虛擬網卡模式」，滿足日常瀏覽器上網至全域應用程式/遊戲接管的不同需求。

🔀

應用程式分流 (App Routing)

針對桌面端不同應用程式自訂專屬分流與代理規則，精準控制哪些軟體走代理節點、哪些保持本地直連 (Direct)。

📈

流量統計與系統診斷

內建即時流量監控圖表、基於 logrus 的詳細結構化連線日誌，以及一鍵系統網路狀態診斷工具 (Diagnostics)。

🗔

系統托盤與視窗管理

整合 tray_manager 與 window_manager，支援最小化至系統托盤背景常駐、快速選單切換與防止多開實例衝突。

Getting Started & Installation

🚀 快速開始與安裝指南

依照您的作業系統選擇預編譯安裝包，並在 3 分鐘內完成訂閱匯入與首次代理連線。

1. 選擇您的作業系統安裝方式

方法 A：下載官方預編譯版本（推薦）
  1. 前往 GitHub Releases 頁面下載最新 Windows 安裝檔（Installer .exe 或免安裝壓縮包）。
  2. 執行安裝程式，確保 aster-bridge.exe 與主程式位於相同執行目錄。
  3. 若需使用 TUN 模式，建議以「系統管理員身分」啟動以建立虛擬網卡介面。
Windows 平台架構特性
  • IPC 通道：採用 github.com/Microsoft/go-winio 實作高效能 Windows 具名管道 (Named Pipes) 通訊。
  • 視窗與托盤：支援縮小至右下角系統匣常駐，並自動防止重複開啟多個程式實例。
  • 建置規格：定義於儲存庫的 windows/ 與 packaging/ 目錄。
方法 A：下載 macOS 應用程式套件
  1. 從 GitHub Releases 下載對應架構（Apple Silicon / Intel）的 .dmg 或 .app 壓縮檔。
  2. 將 Aster Desktop.app 拖曳至 /Applications 資料夾。
  3. 首次開啟若遇 Gatekeeper 提示，可於「系統設定 → 隱私權與安全性」允許開啟。
macOS 平台架構特性
  • 原生整合：基於 Swift 與 Xcode 建置（見 macos/ 目錄），支援 macOS 頂部選單列 (Menu Bar) 常駐控制。
  • 網路接管：支援設定 macOS 網路服務系統代理與 TUN 虛擬網路介面。
方法 A：安裝 Linux 發行版套件
  1. 前往 GitHub Releases 取得 Linux 預編譯套件或透過 packaging/ 腳本打包。
  2. 確認系統已安裝 GTK3 與系統匣支援套件（如 libayatana-appindicator）。
  3. 啟用 TUN 模式時需具備 CAP_NET_ADMIN 權限或透過提權執行 aster-bridge。
Linux 平台架構特性
  • 原生殼層：使用 C++ 與 CMake 建置 GTK 視窗宿主（位於 linux/ 目錄）。
  • 底層系統呼叫：Go Bridge 透過 golang.org/x/sys 管理網路介面與路由表。

🛡️ 代理接管模式比較與情境推薦器

點選您的使用情境，自動醒目提示最適合的 Aster Desktop 運作模式：

💡 推薦模式：系統代理 (System Proxy) — 適合日常 Chrome / Edge / Firefox 網頁瀏覽與支援系統環境變數的桌面應用。無須管理員提權即可快速啟用，系統資源佔用最低。
比較維度 系統代理 (System Proxy) TUN 虛擬網卡模式 (TUN Mode) 應用程式分流 (App Routing)
運作層級 應用層 (HTTP / SOCKS5 系統設定) 網路層 L3 (虛擬網路介面卡攔截) 程序/規則層 (Process & Rule 匹配)
UDP 流量支援 取決於客戶端軟體是否支援 SOCKS5 UDP 完整支援全系統 TCP / UDP 封包 依綁定規則支援 TCP / UDP 分流
系統權限需求 一般使用者權限即可 需管理員 / Root / CAP_NET_ADMIN 權限 搭配 TUN 或 Bridge 底層規則運作
典型適用場景 網頁瀏覽、主流辦公與開發工具 不支援代理設定的桌面遊戲、CLI 工具、全域接管 國內外軟體混合使用、特定程式強制直連或走代理

📝 訂閱管理與內建配置編輯器

yaml + re_editor

Aster Desktop 整合了 yaml (^3.1.3) 與高效能程式碼編輯元件 re_editor (0.10.0)，使用者不僅能透過 URL 遠端拉取並定時更新機場/自建節點訂閱，還能在桌面端直接檢視與微調 YAML 規則配置，搭配 file_selector (^1.1.0) 支援匯入本地設定檔。

📊 即時流量遙測與系統診斷

websocket + logrus

後端 aster-bridge 透過 github.com/coder/websocket 與具名管道持續推送即時上下行頻寬速率、連線狀態與 sirupsen/logrus 結構化日誌。當遇到網路異常時，可透過「診斷 (Diagnostics)」模組快速定位 DNS、路由或節點握手問題。
